# Сводка — дашборд продаж интернет-магазина

Демо-проект для портфолио: магазин и данные вымышленные (около 5 500 заказов за 2 года генерируются в коде).

**Открыть:** https://davnat0111-gif.github.io/svodka-dashboard/

## Что умеет
- **3D-график выручки по месяцам (Three.js):** столбики по категориям, подсказка при наведении, вращение мышкой
- **KPI:** выручка, заказы, средний чек, конверсия, изменение к прошлому периоду и спарклайны
- График выручки по дням с подсказкой и круговая диаграмма категорий (Canvas)
- **Фильтры:** период (7 дней / 30 дней / квартал / год) и категории, все виджеты пересчитываются
- **Таблица заказов:** поиск, фильтр по статусу, сортировка по любой колонке, пагинация, **выгрузка в CSV** (открывается в Excel)

HTML, CSS, JavaScript без фреймворков. Сделано с помощью Claude Code.
